# Remix of Remix of Remix of Remix of Arena On-Demand

Build Ironhowl Arena game: wire everything up. When the game starts the player only needs to download the characters, cars, animations, sounds, etc. and one map which is the Friend Island (make sure it's the Friend Island, not the waiting island). Keep the rest of the maps so the player can click a button to download a specific thing: each other map has an overlay download button so if the player wants to play there they need to download it separately.
